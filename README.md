一、作品主题与创意来源：
灵感来源于作者小时候爱玩4399和7k7k，所以在这次作品中选取了自己以前最爱玩的2048，开火车和stg游戏形式，融合了中财的很多元素：校徽，风景，学习生活...就这样cufe game box诞生了。
二、功能模块：1.封装之后，功能界面分为开始界面，菜单界面和游戏界面。
      2.封装之前，分为html网页，css排版布局，js逻辑，和assets图片配置。
三、运行环境: 整体文件已托管至帽子云，点击链接即可开始游玩。
四、操作步骤：
1.链接：https://cufeemblemaddsgame-10r3r3qh.maozi.io/
2.虽然本文件大部分图片已转化为webp格式，但仍有出现卡顿的风险。如需要本地游玩，请按照以下步骤：
（1）访问GitHub链接：https://github.com/zzzotter/Game_emblem_adds下载源代码
（2）打开命令提示符cmd输入以下内容：
cd 文件夹地址
python -m http.server 8000
在任意浏览器上输入：http://localhost:8000
